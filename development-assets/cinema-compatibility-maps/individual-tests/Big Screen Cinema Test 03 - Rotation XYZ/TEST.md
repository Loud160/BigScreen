# Test 03: Independent X, Y and Z screen rotation

Expected behavior:

- Screen uses rotation x=-8, y=18, z=-10 degrees
- Right edge recedes; frame also rolls clockwise
- Rotation changes the frame, not the pixels inside it

The difficulty intentionally contains no notes, bombs, walls, arcs,
chains, or gameplay objects. Lighting pulses are present to make bloom
and transparency behavior observable.
