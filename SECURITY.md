# Security policy

## Supported version

Security fixes are applied to the newest Big Screen build for the currently documented Beat Saber package version. Older game/mod combinations may not receive backports.

## Reporting

When the repository is published, use GitHub's private vulnerability-reporting feature if enabled. Do not post exploitable downloader, path-handling, update-verification, or native-memory details in a public issue before the maintainer has had a reasonable opportunity to investigate.

Include the Big Screen version, Beat Saber package version, Quest model, reproduction steps, and the smallest relevant log excerpt. Do not attach cookies, tokens, private videos, or complete personal song libraries.

## Scope

Especially relevant reports include path traversal, arbitrary URL fetching, updater verification bypass, unsafe archive handling, memory corruption, cross-thread Unity access, and ways mapper-controlled metadata can affect non-video maps.
